# mingo-mate

macOS 화면 위에 떠 있는 카메라 추적 3D 동물 코스프레 아바타 앱이다. 같은 동물 탈을
색만 바꾼 팩이 아니라 얼굴, 눈, 헤어, 헤드기어, 상·하의 실루엣이 서로 다른 인간형
VTuber 12종을 제공한다.

카메라 영상은 로컬 MediaPipe 처리에만 쓰고 저장하거나 외부 서버로 보내지 않는다.
표정, 고개, 팔, 손과 손가락 움직임은 공통 VRM 리그로 전달된다.

## 실행

```bash
npm install
npm start
```

개발 모드는 `npm run dev`, 타입 검사는 `npm run typecheck`, 프로덕션 빌드는
`npm run build`로 실행한다.

## 캐릭터

| 키 | 캐릭터 | 대표 헤어 | 대표 의상 |
|---|---|---|---|
| `1` | 곰 | 체스트넛 숄더 보브 | 포레스트 바시티와 랩 큐롯 |
| `2` | 원숭이 | 코퍼 하이 포니테일 | 오커 봄버와 와이드 카고 |
| `3` | 거북이 | 틸 언더레이어 블런트 보브 | 테크 하프후디와 등껍질 백팩 |
| `4` | 토끼 | 애쉬 라벤더 트윈테일 | 발레 랩 니트와 러닝 스코트 |
| `5` | 여우 | 번트 코퍼 울프컷 | 비대칭 모토 재킷과 플레어 팬츠 |
| `6` | 판다 | 잉크 블랙 로우 스페이스 번 | 모노크롬 랩 카디건과 와이드 쇼츠 |
| `7` | 펭귄 | 아이스 언더컷 쇼트 크롭 | 스노보드 아노락과 보드 쇼츠 |
| `8` | 부엉이 | 브레이디드 크라운과 로우 브레이드 | 다크 아카데미아 베스트와 케이프 |
| `9` | 사자 | 허니 골드 볼륨 웨이브 | 레지멘털 재킷과 승마형 팬츠 |
| `0` | 호랑이 | 앰버 브레이디드 하이 포니 | 레이싱 재킷과 컴뱃 팬츠 |
| `-` | 코끼리 | 스모키 블루 로우 포니 | 랩 유틸리티 베스트와 배럴 팬츠 |
| `=` | 기린 | 캐러멜 버블 포니 | 롱라인 사파리 베스트와 미디 쇼츠 |

숫자열의 위 키 또는 앱 메뉴에서 전환한다. 마지막 선택은 이 기기의
`localStorage`에만 저장된다.

## 아바타 팩 검증

```bash
npm run avatars:build
npm run avatars:audit
npm run avatars:shots -- --plan
```

`avatars:build`는 카탈로그로부터 12개 VRM을 결정적으로 재생성하고,
`avatars:audit`는 리그·표정 보존, 텍스처 크기, 모델/홍채/의상 고유성을 검사한다.
`avatars:shots`는 12종 × 7장(정면·얼굴·고개·표정·손가락·다리·후면/측면) 렌더 QA 행렬을 만든다.

모델 구조와 검증 방법은 [Animal Avatar Pack](docs/ANIMAL-AVATAR-PACK.md), 새 외형을 추가하는
절차는 [Avatar Pipeline](docs/AVATAR-PIPELINE.md)에 정리되어 있다.
