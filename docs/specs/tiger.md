# 호랑이 / Tiger — 슬롯 `0`

`./models/tiger.vrm`은 레이싱/컴뱃 스포츠웨어에 호랑이 줄무늬를 구조적으로 적용한 인간 VTuber다. 사자보다 더 날카롭고, 여우보다 운동성이 강한 별도 얼굴과 복장을 쓴다.

## 얼굴·헤어 계약

| 항목 | 확정 디자인 |
|---|---|
| 얼굴 인상 | 광대와 턱이 모두 날렵한 다이아몬드형, 낮게 모인 눈썹의 집중력 강한 인상. 코끝은 짧고 콧대는 곧다. |
| 눈매 | 윗눈꺼풀이 깊고 안팎 눈꼬리가 모두 뾰족한 좁은 캣아이. 짙은 네이비 림·코발트 중간색·빙청색 하이라이트의 3단 홍채로 주황 의상과 강하게 대비한다. |
| 입술 | 선명하고 두꺼운 브릭 코랄 입술. 윗입술 중앙은 깊고 아랫입술 가장자리는 매트, 기본 표정은 단단히 다문 집중 표정이다. |
| 머리 실루엣 | 앰버 오렌지 초고 브레이디드 포니. 굵은 검정 로우라이트가 줄무늬처럼 땋임을 따라가고, 관자놀이에 짧은 뾰족 옆머리가 있다. |

## 코스튬 계약

| 항목 | 확정 디자인 |
|---|---|
| 헤드기어 | 오렌지/크림 크롭 레이싱 후드와 둥근 귀. 검은 줄무늬는 표면 데칼이 아니라 패널 절개로 이어지며 포니테일용 후면 포트가 있다. |
| 상의 | 비대칭 오렌지 레이싱 재킷, 크림 압박 탑, 검은 충격 흡수 리브와 목의 짧은 스탠드 칼라. |
| 하의 | 차콜 테이퍼드 컴뱃 팬츠. 한쪽 허벅지의 오렌지 아머 패널, 크림 무릎 인서트와 검정 웨빙이 있다. |
| 신발 | 오렌지/차콜 하이컷 레이싱 스니커즈. 분절 솔, 발목 스트랩과 크림 토 범퍼를 쓴다. |
| 시그니처 액세서리 | 검정 줄무늬 오렌지 꼬리와 한쪽 귀 아래의 푸른 타이거아이 이어커프. 꼬리 끝은 뾰족하지 않고 둥근 털 술이다. |

## 색·재질

- Animalverse 원색: `#EE8A3C / #FFF1DC / #2E2620 / #2E2620`, 구조 그림자 `#C65F26`.
- 레이싱 재킷은 반무광 합성 섬유, 아머는 단단한 TPU, 팬츠는 립스톱, 머리 로우라이트와 꼬리는 방향성 털 결을 쓴다.
- 노란 홍채, 전신 타이거 프린트, 여우와 같은 모토 재킷은 금지한다.

## 모델링·리깅 가드레일

- 포니테일 뿌리 포트가 후드와 함께 움직이며 땋은 머리의 줄무늬가 스프링 변형에서도 끊기지 않는다.
- 아머 패널은 허벅지와 무릎 관절을 걸치지 않고, 웨빙은 다리 리깅 중 몸 안으로 말려들지 않는다.
- 손가락 10개, 손목·팔꿈치·무릎·발목 전 범위를 보존하고 꼬리는 6본 이상으로 만든다.
