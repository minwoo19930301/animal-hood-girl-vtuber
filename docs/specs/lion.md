# 사자 / Lion — 슬롯 `9`

`./models/lion.vrm`은 태양빛 레지멘털 재킷과 볼륨 헤어로 왕성한 에너지를 표현한 인간 VTuber다. 갈기는 모자에 붙인 갈색 원이 아니라 헤어와 후드가 만드는 이중 후광 실루엣이다.

## 얼굴·헤어 계약

| 항목 | 확정 디자인 |
|---|---|
| 얼굴 인상 | 넓은 턱, 높은 광대, 굵고 올라간 눈썹의 당당한 인상. 코와 입 주변은 선명하지만 남성적인 과장은 피한다. |
| 눈매 | 위쪽이 직선이고 바깥이 올라가는 넓은 아몬드형. 짙은 올리브 브라운 림·골드 카키 중간색·샴페인 하이라이트의 3단 홍채다. |
| 입술 | 넓고 도톰한 번트 로즈 입술. 큐피드 보우는 낮고 웃을 때 윗니가 자연스럽게 드러나는 개방적인 형태다. |
| 머리 실루엣 | 허니 골드의 매우 풍성한 숄더 렝스 웨이브. 옆가르마와 뒤로 퍼지는 큰 C/S컬이 둥근 갈기 후광을 만들며 안쪽은 구리색 그림자다. |

## 코스튬 계약

| 항목 | 확정 디자인 |
|---|---|
| 헤드기어 | 황금 브라운 오픈페이스 숄 후드. 둘레의 짧은 플리츠/퍼 패널이 갈기처럼 퍼지고 작은 둥근 귀가 위에 놓인다. 헤어 볼륨을 눌러 납작하게 만들지 않는다. |
| 상의 | 사프란 크롭 레지멘털 재킷, 크림 딥 V 니트, 구리 브레이드 장식과 비대칭 견장. 허리는 몸에 맞고 어깨는 구조적이다. |
| 하의 | 다크 브라운 하이웨이스트 승마형 팬츠. 허벅지는 여유롭고 종아리는 좁으며 금색 옆선 파이핑이 있다. |
| 신발 | 짙은 갈색 미드카프 레이스 부츠. 사자 발을 연상시키는 넓은 앞코, 황금 아일렛과 안정적인 블록 굽을 쓴다. |
| 시그니처 액세서리 | 뒤 허리의 가는 꼬리와 짙은 갈색 술, 가슴의 작은 태양 메달. 꼬리 술은 풍성한 헤어와 다른 방향으로 흔들린다. |

## 색·재질

- Animalverse 원색: `#EBB755 / #FFE9BC / #B5722E / #4A331C`, 구조 그림자 `#C8872E`.
- 재킷은 고밀도 울, 갈기 패널은 짧은 퍼/주름 직물, 니트는 골지, 메달은 브러시드 골드다.
- 여우·호랑이와 주황색만 다른 동일 의상은 실패다. 레지멘털 절개와 승마 팬츠 비율을 지킨다.

## 모델링·리깅 가드레일

- 풍성한 웨이브는 좌우/후면 6개 이상 섹션으로 나눠 어깨와 후드 갈기 패널을 관통하지 않는다.
- 견장과 브레이드가 팔 올림에서 늘어나지 않고, 승마 팬츠는 깊은 런지에서도 무릎 웨이트가 유지된다.
- 꼬리는 5본 이상, 손가락은 10개 독립. 기본 팔은 몸 옆에 자연스럽게 내린다.
