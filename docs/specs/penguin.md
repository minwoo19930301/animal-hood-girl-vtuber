# 펭귄 / Penguin — 슬롯 `7`

`./models/penguin.vrm`은 설원 보드웨어와 1960년대 모드 실루엣을 섞은 인간 VTuber다. 펭귄의 검정/흰색/노랑은 면 분할과 작은 부리 장식으로만 표현한다.

## 얼굴·헤어 계약

| 항목 | 확정 디자인 |
|---|---|
| 얼굴 인상 | 짧은 코와 각진 작은 턱, 침착하지만 재치 있는 인상. 한쪽 눈썹을 짧게 끊어 비대칭 헤어와 균형을 맞춘다. |
| 눈매 | 직선 윗눈꺼풀과 둥근 아래 눈꺼풀이 만나는 중간 크기 눈. 아이스 블루 홍채는 네이비 림·시안 중간색·거의 흰 수면광으로 구성한다. |
| 입술 | 폭이 넓고 세로로 얇은 쿨 로즈 입술. 아랫입술 중앙에만 촉촉한 하이라이트, 기본 입꼬리는 아주 살짝 위로 향한다. |
| 머리 실루엣 | 미드나이트 네이비 비대칭 쇼트 크롭. 오른쪽은 광대까지 내려오고 왼쪽은 귀가 보이는 아이스 블루 언더컷이다. 뒷목은 깔끔히 노출한다. |

## 코스튬 계약

| 항목 | 확정 디자인 |
|---|---|
| 헤드기어 | 네이비 케이프 후드와 이마 위 작은 머스터드 부리형 챙. 얼굴은 완전히 열고, 후드 옆은 펭귄 날개처럼 납작한 패널로 어깨까지 이어진다. |
| 상의 | 흰색 중심 패널과 네이비 옆판의 짧은 스노보드 아노락. 머스터드 방수 지퍼와 소매 티켓 포켓이 있다. |
| 하의 | 네이비 A라인 보드 쇼츠와 검정 압박 레깅스. 옆 솔기는 빙산처럼 각진 흰색 인서트로 분할한다. |
| 신발 | 네이비/아이스 블루 하이컷 스노 러너. 머스터드 아웃솔과 넓은 파워 스트랩, 둥근 토를 쓴다. |
| 시그니처 액세서리 | 왼쪽 허리의 반투명 얼음 물고기 키체인과 노란 카라비너. 케이프와 다른 주기로 흔들린다. |

## 색·재질

- Animalverse 원색: `#31394A / #F6F8FA / #F5B940 / #20242E`, 구조 그림자 `#1E2532`.
- 아노락은 방수 나일론, 케이프는 얇은 소프트셸, 레깅스는 매트 스트레치, 키체인은 투명 굴절 재질이다.
- 긴 뒷머리나 일반 후디 몸판, 새 부리를 얼굴 앞에 붙이는 표현은 금지한다.

## 모델링·리깅 가드레일

- 비대칭 크롭은 두피가 드러나지 않고, 후드 패널과 귀 주변에서 Z-fighting이 없어야 한다.
- 케이프 양 패널은 어깨에 붙지 않는 별도 보조 본이며 팔을 올릴 때 자연스럽게 벌어진다.
- 쇼츠와 레깅스는 무릎·고관절 웨이트를 분리하고 손가락 10개를 모두 추적한다.
