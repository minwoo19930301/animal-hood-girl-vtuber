# 여우 / Fox — 슬롯 `5`

`./models/fox.vrm`은 날렵한 모토 재킷과 테일러링을 섞은 인간 VTuber다. 동물성은 귀와 꼬리, 컬러 블로킹으로만 전달하고 실제 여우 얼굴이나 주둥이를 붙이지 않는다.

## 얼굴·헤어 계약

| 항목 | 확정 디자인 |
|---|---|
| 얼굴 인상 | 긴 V라인 턱과 높은 콧대, 살짝 치켜뜬 눈썹으로 자신감 있고 영리한 인상. 광대 그림자는 가늘고 선명하다. |
| 눈매 | 바깥 눈꼬리가 길게 올라간 폭스아이. 흰자는 안쪽에 넉넉히 남고, 짙은 솔잎색 림·에메랄드 중간색·연두 반사광의 3단 홍채를 쓴다. |
| 입술 | 중간보다 두꺼운 테라코타 로즈 입술. 윗입술 산은 날카롭고 아랫입술 중앙에 작은 광택, 기본 표정은 닫힌 자신감 있는 미소다. |
| 머리 실루엣 | 번트 코퍼 롱 울프컷. 정수리는 짧고 뒤는 견갑까지 층층이 내려오며, 끝과 안쪽 레이어는 짙은 갈색으로 꼬리의 그라데이션과 맞춘다. |

## 코스튬 계약

| 항목 | 확정 디자인 |
|---|---|
| 헤드기어 | 정수리 뒤로 젖힌 짧은 러스트 모토 후드와 삼각 여우 귀. 귀는 후드에 봉제된 코스프레 구조이며 검은 팁과 크림 안감이 있다. |
| 상의 | 비대칭 지퍼의 러스트 크롭 모토 재킷, 크림 하이넥 리브 탑, 짙은 갈색 하네스 벨트. 어깨 보호대는 작고 날렵하다. |
| 하의 | 다크 초콜릿 슬림 플레어 팬츠. 한쪽 허벅지 패널과 크림 사이드 인서트, 무릎 뒤 절개로 기동성을 만든다. |
| 신발 | 뾰족한 토가 아닌 좁은 라운드 토의 앵클 모토 부츠. 낮은 사선 굽, 구리 버클과 크림 웰트가 있다. |
| 시그니처 액세서리 | 허리의 대형 부시 테일. 러스트에서 크림 끝으로 이어지는 털 결 그라데이션과 6본 이상 스프링 체인을 사용한다. |

## 색·재질

- Animalverse 원색: `#E8833A / #FFF4E3 / #C9622B / #3B2A20`, 구조 그림자 `#B85A26`.
- 재킷은 반무광 인조가죽, 상의는 골지 니트, 팬츠는 스트레치 울, 꼬리는 방향성 퍼 셰이더로 명확히 분리한다.
- 원숭이의 봄버/조거, 호랑이의 레이싱 기어와 재봉선·포켓 형태를 공유하지 않는다.

## 모델링·리깅 가드레일

- 울프컷 끝과 꼬리는 별도 충돌 그룹이며 어깨·허리·다리 안으로 파고들지 않는다.
- 모토 재킷 지퍼와 하네스가 흉부 변형에서 떠오르지 않으며, 플레어 팬츠 밑단은 발목 회전을 방해하지 않는다.
- 손가락 10개를 보이며 기본 팔 자세는 교차하지 않는다.
