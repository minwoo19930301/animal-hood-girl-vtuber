# 원숭이 / Monkey — 슬롯 `2`

`./models/monkey.vrm`은 민첩한 스트리트 댄서 콘셉트의 인간 VTuber다. `refs/avatar-pack/bear-monkey-turtle.png` 중앙의 높은 포니테일, 황토색 재킷, 버건디 카고 실루엣을 기준으로 한다.

## 얼굴·헤어 계약

| 항목 | 확정 디자인 |
|---|---|
| 얼굴 인상 | 타원형 얼굴과 높은 광대, 한쪽 눈썹이 미세하게 올라간 장난기 있는 표정. 곰보다 턱선이 길고 여우보다 부드럽다. |
| 눈매 | 눈꼬리가 선명하게 올라간 좁고 긴 아몬드형. 청록 홍채는 짙은 틸 림·투명한 아쿠아 중간색·민트 캐치라이트로 구성한다. |
| 입술 | 윗입술 산이 뚜렷한 도톰한 코랄 브라운 입술. 비대칭 스마일을 기본으로 하되 송곳니는 웃을 때만 아주 짧게 보인다. |
| 머리 실루엣 | 구리빛 초고 포니테일과 긴 S컬 묶음, 양쪽 턱까지 오는 가는 옆머리. 이마 중앙의 한 가닥 소용돌이가 원숭이 꼬리와 형태적으로 대응한다. |

## 코스튬 계약

| 항목 | 확정 디자인 |
|---|---|
| 헤드기어 | 캐러멜/브라운 오픈페이스 크롭 후드. 옆으로 돌출된 둥근 귀는 베이지 안감과 실제 두께가 있고, 정수리 뒤쪽은 포니테일이 통과하도록 절개된다. |
| 상의 | 머스터드 크롭 봄버, 버건디 리브, 크림 스포츠 브라톱. 지퍼·소매 포켓·통풍 메시를 별도 재질로 만든다. |
| 하의 | 와이드 버건디 조거 카고 팬츠. 비대칭 포켓, 노란 드로코드, 외측 파이핑과 발목 셔링이 있는 파쿠르 실루엣이다. |
| 신발 | 크림/버건디 러닝 스니커즈, 꿀색 아웃솔 포인트와 분절된 쿠션 솔. |
| 시그니처 액세서리 | 허리 뒤에서 시작하는 길고 유연한 갈색 코스프레 꼬리. 끝이 자연스러운 나선이며 5개 이상 스프링 본을 쓴다. |

## 색·재질

- Animalverse 원색: `#A9764C / #F1D9BE / #8A5A34 / #3B2A1C`, 구조 그림자 `#7A4A2E`.
- 봄버는 얇은 나일론, 브라톱은 매트 저지, 팬츠는 사각거리는 립스톱, 꼬리는 짧은 벨벳 퍼로 구분한다.
- 다른 캐릭터의 스커트, 동일 보브 헤어, 단순 원통 꼬리를 재사용하지 않는다.

## 모델링·리깅 가드레일

- 포니테일은 후드와 절대 관통하지 않으며 묶음 뿌리·중간·끝을 3계층 이상으로 나눠 추적한다.
- 꼬리는 골반 회전을 따르되 손과 다리 충돌 반경을 가지고, 정면에서 허벅지로 오인되지 않아야 한다.
- 넓은 카고 팬츠는 무릎·발목 굽힘에 맞춰 접히고, 손가락 10개와 손목 회전 범위를 모두 유지한다.
