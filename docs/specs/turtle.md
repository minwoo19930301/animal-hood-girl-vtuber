# 거북이 / Turtle — 슬롯 `3`

`./models/turtle.vrm`은 잠수·탐험 장비를 스트리트 테크웨어로 재해석한 인간 VTuber다. `refs/avatar-pack/bear-monkey-turtle.png` 오른쪽의 청록 쇼트 후드, 검정 카고와 실제 등껍질 백팩을 기준으로 한다.

## 얼굴·헤어 계약

| 항목 | 확정 디자인 |
|---|---|
| 얼굴 인상 | 직선형 턱과 낮은 광대, 차분하고 관찰력이 강한 인상. 12종 중 가장 모던하고 냉정한 얼굴 비율이다. |
| 눈매 | 길고 날카로운 평행사변형에 가까운 아몬드형. 윗눈꺼풀은 굵고 아래는 가늘다. 청록/시안 홍채는 짙은 바다색 림과 밝은 수면 반사 하이라이트를 가진다. |
| 입술 | 폭이 좁고 아랫입술만 도톰한 누드 로즈. 입꼬리는 수평이며 발음할 때도 과하게 둥글어지지 않는다. |
| 머리 실루엣 | 턱선에서 정확히 끊기는 블루블랙 블런트 보브와 짧은 직선 앞머리. 안쪽 레이어만 청록이라 고개를 돌릴 때 색이 드러난다. |

## 코스튬 계약

| 항목 | 확정 디자인 |
|---|---|
| 헤드기어 | 청록색 쇼트 카울. 육각 등딱지 패널을 톤온톤 엠보싱하고 얼굴 둘레는 짙은 바인딩, 어깨 위에서 끝나는 구조다. 동물 머리 모양 탈은 쓰지 않는다. |
| 상의 | 한쪽 어깨가 트인 민트 테크 하프후디. 비대칭 스트랩, 주황 파이핑, 방수 지퍼와 전면 캥거루 포켓이 있다. |
| 하의 | 차콜 테이퍼드 카고 팬츠. 좌우 포켓 형태가 다르고 민트 웨빙, 무릎 다트, 검정 버클을 갖는다. |
| 신발 | 민트/차콜 트레일 러너. 오렌지 끈, 깊은 러그 아웃솔과 발목 보호 패널이 있다. |
| 시그니처 액세서리 | 실제 부피를 가진 짙은 초록 육각 등껍질 백팩. 어깨 스트랩·허리 버클이 몸을 감싸고 작은 산소 게이지 참이 달린다. |

## 색·재질

- Animalverse 원색: `#7FB069 / #DCEBC4 / #5B7C4A / #31431F`, 구조 그림자 `#4F7C48`.
- 상의는 방수 소프트셸, 팬츠는 매트 나일론, 등껍질은 반무광 하드셸, 웨빙은 직조 노멀을 분리한다.
- 기존 긴 뒷머리, 교복 치마, 평면 등껍질 데칼은 반드시 제거한다.

## 모델링·리깅 가드레일

- 짧은 보브의 목 뒤 공간이 보여야 하며 카울 뒤와 겹쳐 검은 덩어리가 되지 않는다.
- 등껍질은 흉추를 따라가되 척추 굽힘에서 등에 파묻히지 않고, 스트랩은 어깨 관절을 가로질러 찢어지지 않는다.
- 손가락 10개, 팔꿈치, 무릎, 발목을 전부 추적한다. 기본 손은 반쯤 펴진 자연스러운 형태다.
