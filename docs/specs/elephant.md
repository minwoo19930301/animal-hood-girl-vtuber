# 코끼리 / Elephant — 슬롯 `-`

`./models/elephant.vrm`은 넓고 안정적인 소프트 아머와 유틸리티 웨어를 입은 인간 VTuber다. 코끼리의 큰 귀와 코는 후드의 봉제 구조로만 표현하며 사람 얼굴을 가리는 코 가면은 만들지 않는다.

## 얼굴·헤어 계약

| 항목 | 확정 디자인 |
|---|---|
| 얼굴 인상 | 넓은 광대와 부드러운 사각 턱, 길고 낮은 눈썹. 성숙하고 포용력 있는 인상이며 코는 다른 캐릭터보다 약간 길되 과장하지 않는다. |
| 눈매 | 바깥쪽이 조금 내려가는 길고 낮은 아몬드형. 짙은 인디고 림·라벤더 블루 중간색·서리빛 하이라이트의 3단 홍채다. |
| 입술 | 가장 두꺼운 축에 속하는 플럼 로즈 입술. 큐피드 보우는 넓고 아랫입술은 볼륨이 풍부하며, 짙은 피부에서도 색과 광택이 분명하다. |
| 머리 실루엣 | 스모키 블루그레이 로우 포니와 긴 사이드스웹 프린지. 뒷머리는 목 아래에서 하나의 넓은 리본처럼 모이고 끝은 둥글게 말린다. |

## 코스튬 계약

| 항목 | 확정 디자인 |
|---|---|
| 헤드기어 | 파우더 블루 오픈페이스 구조 후드. 좌우 큰 부채꼴 귀는 다층 패브릭, 이마 위의 짧은 봉제 코는 위로 말려 얼굴에 닿지 않는다. 핑크 안감은 귀 안쪽에만 쓴다. |
| 상의 | 슬레이트 블루 랩 유틸리티 베스트와 밝은 회청색 풍선 소매. 가슴은 비대칭 버클, 옆구리는 퀼팅 소프트 아머다. |
| 하의 | 짙은 인디고 배럴 팬츠. 무릎에 볼륨을 두고 발목에서 좁아지며, 큰 곡선 포켓과 회청색 스티치가 있다. |
| 신발 | 넓은 토 박스의 슬레이트 하이킹 부츠. 핑크 힐 풀, 회색 러그 솔과 두꺼운 원형 끈을 사용한다. |
| 시그니처 액세서리 | 허리의 작은 은색 기억 캡슐과 귀 아래의 핑크 매듭. 캡슐 내부에 별 모양 유리가 떠 있다. |

## 색·재질

- Animalverse 원색: `#9BA8BC / #C9D3E0 / #F0A7B4 / #3D4350`, 구조 그림자 `#6F7B91`.
- 후드 귀는 두께 있는 퀼팅, 소매는 브러시드 코튼, 베스트는 매트 소프트셸, 캡슐은 금속/유리로 구분한다.
- 귀를 얇은 평면으로 만들거나 코를 사람 코 위에 붙이는 표현, 다른 캐릭터의 슬림 팬츠 재사용을 금지한다.

## 모델링·리깅 가드레일

- 큰 후드 귀는 각각 3개 이상 보조 본과 제한 각도를 가지며 머리 회전에서 어깨·얼굴을 관통하지 않는다.
- 짧은 봉제 코는 표정 리그와 독립하고 시선·입 추적을 가리지 않는다.
- 배럴 팬츠는 고관절/무릎 굽힘에서 볼륨을 유지하고, 풍선 소매 밖으로 손가락 10개가 온전히 보인다.
