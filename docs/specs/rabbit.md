# 토끼 / Rabbit — 슬롯 `4`

`./models/rabbit.vrm`은 흰 토끼 모티프를 발레와 애슬레저로 풀어낸 인간 VTuber다. 부드러운 색만 쓰되 곰의 캠프웨어나 판다의 모노크롬과 실루엣이 겹치지 않아야 한다.

## 얼굴·헤어 계약

| 항목 | 확정 디자인 |
|---|---|
| 얼굴 인상 | 좁은 턱, 볼 중앙의 밝은 혈색, 호기심 많은 정면 응시. 얼굴 길이는 짧지만 유아형 비율은 피한다. |
| 눈매 | 세로폭이 큰 둥근 아몬드형과 아래로 길게 빠지는 속눈썹. 장밋빛 자주 홍채는 진한 플럼 림·로즈 중간색·유백색 핑크 하이라이트의 3단이다. |
| 입술 | 도톰한 아랫입술과 작은 하트형 윗입술. 딸기 우유색 반투명 틴트, 닫힌 입에서도 입술 경계가 사라지지 않는다. |
| 머리 실루엣 | 애쉬 라벤더 허리 길이 트윈 리본 테일. 정수리 볼륨은 낮고, 광대 옆 두 가닥과 끝이 둥근 굵은 웨이브가 세로 실루엣을 만든다. |

## 코스튬 계약

| 항목 | 확정 디자인 |
|---|---|
| 헤드기어 | 탈착형 아이보리 볼레로 후드와 2단 관절의 긴 토끼 귀. 귀 안쪽은 블러시 핑크 스웨이드, 끝은 힘없이 접힐 수 있지만 기본은 비대칭 직립이다. |
| 상의 | 크로스 랩 형태의 아이보리 발레 니트와 핑크 메시 요크, 손등까지 오는 엄지홀 워머. 허리 리본은 실제 매듭 두께를 갖는다. |
| 하의 | 진주빛 플리츠 러닝 스코트와 안쪽 핑크 바이커 쇼츠. 뛰어도 속옷처럼 보이지 않는 이중 구조다. |
| 신발 | 발레 리본 디테일을 넣은 화이트 하이컷 러닝화. 반투명 핑크 젤 아웃솔과 짧은 레그워머를 결합한다. |
| 시그니처 액세서리 | 허리 뒤의 작은 퍼 폼폼 꼬리와 손목의 당근 모양 미니 파우치. 파우치는 소매와 독립해 흔들린다. |

## 색·재질

- Animalverse 원색: `#F5F0EA / #FFFFFF / #F5A9B8 / #3A3335`, 구조 그림자 `#D8CEC3`.
- 니트, 메시, 새틴 리본, 젤 솔, 퍼 꼬리의 러프니스가 서로 달라야 하며 흰색 면은 회색 그림자로 형태를 보존한다.
- 토끼 귀를 단 기존 교복 캐릭터처럼 보이면 실패다. 상·하의 패턴과 헤어 전체를 독립 제작한다.

## 모델링·리깅 가드레일

- 긴 귀는 각 3본 이상, 트윈테일은 좌우 4본 이상으로 구성한다. 서로와 어깨를 관통하지 않도록 충돌체를 둔다.
- 스코트 플리츠는 골반이 아닌 분할 본으로 후행하며, 깊은 다리 벌림에서도 바이커 쇼츠와 지오메트리가 역전되지 않는다.
- 손가락 10개와 손목을 완전히 노출하고 워머가 손가락 리깅을 덮지 않는다.
