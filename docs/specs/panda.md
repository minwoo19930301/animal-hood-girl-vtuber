# 판다 / Panda — 슬롯 `6`

`./models/panda.vrm`은 부드러운 라운지 테일러링과 그래픽 모노크롬을 결합한 인간 VTuber다. 흑백만 칠한 기존 모델이 아니라 얼굴·헤어·패턴·비율부터 독립된 캐릭터여야 한다.

## 얼굴·헤어 계약

| 항목 | 확정 디자인 |
|---|---|
| 얼굴 인상 | 넓은 이마, 둥근 턱, 낮고 부드러운 눈썹의 느긋한 인상. 눈 밑에 아주 옅은 라일락 음영을 넣어 팬더 아이패치를 화장으로 암시한다. |
| 눈매 | 가로폭은 짧고 세로폭이 있는 둥근 아몬드형. 회보라 홍채는 먹색 림·뮤트 플럼 중간색·진주 라일락 하이라이트다. |
| 입술 | 세로 볼륨이 있는 로즈 베이지 입술. 큐피드 보우는 둥글고 입꼬리는 수평, 아랫입술에 새틴 광택이 남는다. |
| 머리 실루엣 | 잉크 블랙의 낮은 스페이스 번 두 개와 두꺼운 블런트뱅. 번 아래에는 목 중앙까지 오는 짧은 단발만 남겨 완전히 둥근 외곽을 만든다. |

## 코스튬 계약

| 항목 | 확정 디자인 |
|---|---|
| 헤드기어 | 오프화이트 크롭 후드 캡, 검은 반구형 귀와 눈 주변을 연상시키는 곡선 패널. 사람 눈 위에 실제 검은 패치를 덮지 않는다. |
| 상의 | 크림 랩 카디건과 검은 새틴 캐미솔, 넓은 드롭 숄더. 소매 끝은 검은 리브로 정리한다. |
| 하의 | 비대칭 흑백 패널의 하이웨이스트 와이드 쇼츠와 반투명 검정 타이츠. 쇼츠는 라운지웨어처럼 부드럽지만 재단선이 선명하다. |
| 신발 | 둥근 토의 흑백 플랫폼 메리제인 스니커즈. 발등 스트랩과 대나무색 작은 스티치가 있다. |
| 시그니처 액세서리 | 옆 허리에 매단 대나무 모양 보온병과 녹색 제이드 링. 보온병은 작은 체인으로 독립 움직임을 가진다. |

## 색·재질

- Animalverse 원색: `#F7F4EF / #FFFFFF / #2E2B2C / #2E2B2C`, 구조 그림자 `#D6D1CB`.
- 카디건은 부드러운 브러시드 니트, 캐미솔은 새틴, 쇼츠는 텐셀, 타이츠는 낮은 투명도로 흑백 영역의 질감을 분리한다.
- 검정 홍채·검정 입술·검정 얼굴 덩어리를 금지한다. 눈과 입의 미세 색은 반드시 살아 있어야 한다.

## 모델링·리깅 가드레일

- 스페이스 번과 후드 귀는 서로 다른 지오메트리로 읽혀야 하고, 머리 회전 시 겹쳐 한 덩어리가 되지 않는다.
- 랩 카디건은 흉부·어깨 웨이트를 공유하되 앞섶 겹침이 뒤집히지 않는다.
- 타이츠를 포함해 다리 관절이 보존되고 손가락 10개가 긴 소매 밖에서 모두 움직인다.
