# 부엉이 / Owl — 슬롯 `8`

`./models/owl.vrm`은 야간 관측가의 다크 아카데미아와 짧은 날개 케이프를 결합한 인간 VTuber다. 큰 눈만 붙인 캐릭터가 아니라 얼굴형·헤어·소재와 동작까지 조용한 부엉이 인상을 만든다.

## 얼굴·헤어 계약

| 항목 | 확정 디자인 |
|---|---|
| 얼굴 인상 | 넓은 눈썹뼈와 타원형 얼굴, 낮고 곧은 코. 입을 다물면 침착하고 웃으면 따뜻해지는 성숙한 인상이다. |
| 눈매 | 가로·세로가 모두 큰 원형 아몬드지만 안쪽 눈꼬리는 날카롭다. 짙은 세피아 림·황금 앰버 중간색·크림색 초승달 반사의 3단 홍채다. |
| 입술 | 가운데가 도톰하고 양끝이 가는 시나몬 로즈 입술. 윗입술은 매트, 아랫입술은 은은한 새틴으로 분리한다. |
| 머리 실루엣 | 코코아 브라운 브레이디드 크라운과 견갑 아래까지 오는 굵은 로우 브레이드. 관자놀이의 깃털형 잔머리가 얼굴을 감싼다. |

## 코스튬 계약

| 항목 | 확정 디자인 |
|---|---|
| 헤드기어 | 짙은 갈색 니트/가죽 혼합 관측 후드. 위쪽의 짧은 귀깃 두 개와 눈썹을 닮은 V자 스티치, 크림색 안감이 있다. |
| 상의 | 아이보리 하이넥 블라우스, 코코아 더블브레스트 베스트, 팔꿈치 아래로 갈라지는 짧은 깃털 케이프. |
| 하의 | 앰버 체크 하이웨이스트 테이퍼드 슬랙스. 무릎 아래로 가늘어지고 옆선에 어두운 파이핑이 있다. |
| 신발 | 다크 브라운 레이스업 옥스퍼드 부츠. 앰버 스티치와 낮은 적층 굽, 발목의 작은 깃 금속 장식이 있다. |
| 시그니처 액세서리 | 가슴의 달 위상 브로치와 허리의 작은 접이식 별 지도. 브로치 중심은 홍채와 같은 금색 유리다. |

## 색·재질

- Animalverse 원색: `#8C6849 / #E8D5B8 / #F0B429 / #33261B`, 구조 그림자 `#65482F`.
- 케이프는 미세 깃 방향성을 가진 울, 베스트는 매트 트윌, 블라우스는 부드러운 면, 브로치는 금속/유리로 분리한다.
- 실제 부엉이 얼굴 디스크를 사람 얼굴 위에 씌우거나 단순 망토로 날개를 대신하지 않는다.

## 모델링·리깅 가드레일

- 브레이디드 크라운은 후드 아래에서도 형태가 보이고, 로우 브레이드는 목·케이프와 충돌하지 않는 5본 이상 체인이다.
- 케이프 좌우는 팔과 별도 보조 본으로 접히며, 팔을 내렸을 때 손과 손가락을 가리지 않는다.
- 큰 눈은 눈꺼풀 폐합 시 홍채가 남지 않고, 시선 추적 범위 끝에서도 흰자가 비정상적으로 뒤집히지 않는다.
