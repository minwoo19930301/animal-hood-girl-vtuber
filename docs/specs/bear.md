# 곰 / Bear — 슬롯 `1`

`./models/bear.vrm`은 곰 탈을 쓴 사람이 아니라, 빈티지 캠프웨어를 자기 스타일로 소화한 인간 VTuber다. `refs/avatar-pack/bear-monkey-turtle.png`의 왼쪽 디자인을 비율·재질·컬러 블로킹 기준으로 삼는다.

## 얼굴·헤어 계약

| 항목 | 확정 디자인 |
|---|---|
| 얼굴 인상 | 둥근 볼과 짧은 턱, 편안하고 신뢰감 있는 인상. 코끝과 광대에 옅은 주근깨를 넣되 아동형 치비 얼굴로 만들지 않는다. |
| 눈매 | 바깥쪽이 살짝 내려가는 큰 아몬드형. 흰자가 분명히 보이고, 호박색 홍채는 진갈색 외곽선·캐러멜 중간색·꿀빛 하이라이트의 3단 구조다. |
| 입술 | 중간 두께의 둥근 큐피드 보우. 무표정에서도 입꼬리가 아주 조금 올라가며, 윗입술은 로즈 브라운·아랫입술 중앙은 코랄 글로스다. |
| 머리 실루엣 | 쇄골 위 체스트넛 보브, 중앙에서 갈라지는 커튼뱅과 굵은 C컬 끝. 좌우 볼륨이 균형 잡히고 후드 밖으로 끝머리가 보여야 한다. |

## 코스튬 계약

| 항목 | 확정 디자인 |
|---|---|
| 헤드기어 | 입체 봉제선과 짧은 털 노멀을 가진 코코아색 오픈페이스 후드. 둥근 귀 두 개, 크림색 주둥이 자수, 작은 갈색 코가 정수리 위에 있다. 사람 얼굴을 침범하는 곰 마스크는 금지한다. |
| 상의 | 딥 포레스트 몸판·아이보리 소매의 루즈핏 바시티 재킷과 골지 크림 크롭 니트. 소매에는 작은 발바닥 패치, 금속 스냅과 리브 조직이 실제 두께를 가져야 한다. |
| 하의 | 하이웨이스트 카멜 랩 큐롯. 앞은 스커트처럼 보이지만 다리 사이 분할과 큰 사각 포켓이 있는 활동형 쇼츠다. |
| 신발 | 크림/카멜 하이톱 스니커즈, 짙은 초록 끈, 두꺼운 고무 아웃솔과 루즈 삭스. |
| 시그니처 액세서리 | 오른쪽 벨트 루프의 작은 테디 키링. 몸과 독립된 스프링 본으로 한 박자 늦게 흔들린다. |

## 색·재질

- Animalverse 원색: `#8D6142 / #D9B896 / #6B4830 / #33221A`, 구조 그림자 `#65402D`.
- 재킷은 무광 멜턴+새틴 소매, 니트는 미세 러프니스, 큐롯은 워시드 코튼, 키링은 짧은 퍼로 서로 읽혀야 한다.
- 기존 교복 리본·교복 주름치마·동일 헤어 텍스처가 한 픽셀이라도 남으면 실패다.

## 모델링·리깅 가드레일

- 후드와 곰 귀는 머리 회전을 따르되 볼·눈썹·귀 앞머리를 가리지 않는다. 후드 뒤판과 보브 끝은 별도 스프링 체인이다.
- 재킷 소매는 팔꿈치 120도 굽힘에서 찢어지지 않고, 큐롯은 고관절 70도 벌림에서 다리 사이가 붙지 않는다.
- 손가락 10개는 모두 독립 관절이며 기본 포즈는 팔을 자연스럽게 내린 자세다.
