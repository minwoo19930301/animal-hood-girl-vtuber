# Animal Avatar Pack

`mingo-mate`의 로컬 MediaPipe 추적과 VRM 휴머노이드 리그를 공유하면서 외형만 교체하는
첫 번째 캐릭터 팩이다. 외부 AI나 API 키를 사용하지 않는다.

| 키 | 캐릭터 | 얼굴 구분 | 의상 구분 |
|---|---|---|---|
| 1 | 곰 | 둥근 귀, 크림 주둥이, 검은 코, 두꺼운 눈썹 | 포레스트 그린 바시티 재킷, 크림 소매 |
| 2 | 원숭이 | 큰 옆귀, 피치색 얼굴 패드와 주둥이, 말린 앞머리 | 머스터드 봄버, 버건디 트림 |
| 3 | 거북이 | 청록 카울, 옅은 얼굴 프레임, 작은 콧구멍 | 민트 후디, 오렌지 파이핑, 등딱지 백팩 |

앱 메뉴의 **캐릭터** 항목이나 숫자키 `1`/`2`/`3`으로 전환한다. 선택은
`localStorage`의 `mingo-avatar`에 저장되며 네트워크로 전송되지 않는다. 룩덱 하네스에서는
`?avatar=bear`, `?avatar=monkey`, `?avatar=turtle` 쿼리로 같은 모델을 결정적으로 렌더한다.

각 외형 모듈은 `src/model/animals/`에 있으며, 얼굴 파츠는 head 본, 몸통 의상은 chest 본,
소매는 양쪽 upperArm 본에 붙는다. 따라서 기존 얼굴 표정·고개·팔·손가락 추적 경로를
그대로 사용한다.
