# Animal Avatar Pack

`mingo-mate`의 로컬 MediaPipe 추적과 VRM 휴머노이드 리그를 공유하는 인간형 동물
코스프레 캐릭터 팩이다. 12종은 하나의 얼굴이나 옷에 귀만 바꾼 변형이 아니라 얼굴 인상,
홍채, 헤어 실루엣, 헤드기어, 상·하의와 시그니처 소품을 각각 독립적으로 갖는다.
런타임 추적에는 외부 AI, API 키, 로컬 LLM이 필요하지 않다.

| 키 | 캐릭터 | 얼굴·헤어 구분 | 코스튬 구분 |
|---|---|---|---|
| `1` | 곰 | 부드러운 아몬드 눈, 호박색 홍채, 체스트넛 숄더 보브 | 둥근 귀 오픈 후드, 포레스트 바시티, 랩 큐롯 |
| `2` | 원숭이 | 올라간 눈매, 청록 홍채, 코퍼 하이 포니테일 | 포니테일 포트 후드, 오커 봄버, 와이드 카고 |
| `3` | 거북이 | 직선 눈매, 시안 홍채, 틸 언더레이어 블런트 보브 | 쇼트 카울, 테크 하프후디, 등껍질 백팩 |
| `4` | 토끼 | 세로로 큰 눈, 로즈 홍채, 라벤더 트윈테일 | 관절 귀 볼레로 후드, 발레 랩 니트, 러닝 스코트 |
| `5` | 여우 | 긴 폭스아이, 에메랄드 홍채, 코퍼 울프컷 | 삼각 귀 모토 후드, 비대칭 재킷, 부시 테일 |
| `6` | 판다 | 둥근 눈, 회보라 홍채, 로우 스페이스 번 | 반구 귀 후드 캡, 랩 카디건, 와이드 쇼츠 |
| `7` | 펭귄 | 직선 윗눈꺼풀, 아이스 블루 홍채, 비대칭 쇼트 크롭 | 부리형 챙 케이프 후드, 스노보드 아노락 |
| `8` | 부엉이 | 큰 원형 아몬드 눈, 앰버 홍채, 브레이디드 크라운 | 귀깃 관측 후드, 아카데미아 베스트, 깃털 케이프 |
| `9` | 사자 | 넓고 올라간 눈, 골드 카키 홍채, 볼륨 웨이브 | 갈기형 숄 후드, 레지멘털 재킷, 승마형 팬츠 |
| `0` | 호랑이 | 좁은 캣아이, 코발트 홍채, 브레이디드 하이 포니 | 패널 줄무늬 레이싱 후드, 컴뱃 팬츠, 줄무늬 꼬리 |
| `-` | 코끼리 | 길고 낮은 눈, 라벤더 블루 홍채, 로우 포니 | 다층 귀와 봉제 코 후드, 유틸리티 베스트, 배럴 팬츠 |
| `=` | 기린 | 와이드 아몬드 눈, 헤이즐 홍채, 버블 포니 | 오시콘 헤드밴드, 사파리 베스트, 미디 쇼츠 |

앱 메뉴의 **캐릭터** 항목이나 `1`–`9`, `0`, `-`, `=` 키로 전환한다. 선택은
`localStorage`의 `mingo-avatar`에 저장되며 네트워크로 전송되지 않는다. 룩덱
하네스에서는 `?avatar=<slug>` 쿼리로 같은 모델을 결정적으로 렌더한다. 예:
`?avatar=bear`, `?avatar=tiger`, `?avatar=giraffe`.

## 구조

- `shared/avatar-catalog.json`: 12종의 키, 모델 URL, 눈·헤어·의상 팔레트를 정하는 단일
  카탈로그다. Electron 메뉴와 렌더러가 함께 읽는다.
- `public/models/<slug>.vrm`: 배포에 포함하는 12개 완성 VRM이다.
- `src/model/animals/`: 본에 붙는 종별 헤드기어, 헤어, 의상과 2차 모션을 구성한다.
- `docs/specs/<slug>.md`: 얼굴·눈·입술·헤어·의상과 판정 샷의 캐릭터별 계약이다.
- `refs/avatar-pack/`: 디자인 라인업 레퍼런스다.

얼굴 파츠와 헤어는 head 본, 몸통 의상은 chest/hips 본, 소매와 손 장식은 각 팔·손 본에
붙는다. 모든 캐릭터는 공통 얼굴 표정, 고개, 팔, 손가락, 하체 추적 경로를 유지한다.

## 재현과 검증

```bash
npm run avatars:build
npm run avatars:audit
npm run avatars:shots
```

`avatars:build`는 베이스 VRM과 카탈로그로부터 텍스처·재질을 재생성한다. 중간 PNG,
재질 패치와 매니페스트는 `work/avatar-pack/`에 생성되며 버전 관리하지 않는다.
완성된 `public/models/{bear,monkey,turtle,rabbit,fox,panda,penguin,owl,lion,tiger,elephant,giraffe}.vrm`
12개는 앱 배포 자산이므로 버전 관리한다.

`avatars:audit`는 정확히 12종인지 확인하고 다음 조건을 모두 검사한다.

- GLB/VRM 구조가 유효하고 베이스의 휴머노이드 본과 표정 정의가 보존될 것
- 편집 PNG와 내장 텍스처의 크기 및 해시가 일치할 것
- 모든 모델, 텍스처 묶음, 홍채, 상의 텍스처 해시가 서로 다를 것
- 카탈로그 이름, 모델 메타데이터와 생성 매니페스트가 일치할 것

CI는 임시 디렉터리에 중간물과 비교용 모델을 결정적으로 재생성한다. 이어서 생성
매니페스트의 해시와 커밋된 `public/models/`를 감사하므로 누락되거나 오래된 완성 VRM이
있으면 실패한다. 렌더 QA는
`shots/avatar-pack/<slug>/{front,face,pitch,blink-mouth,hands-fingers,body-legs,orbit}.png`의
12종 × 7장 행렬로 별도 수행한다.
