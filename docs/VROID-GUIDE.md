# VRoid Studio로 진짜 캐릭터 만들기 (예상 30~60분)

목표: `refs/target-human.png`의 여성을 VRoid로 재현 → VRM 내보내기 → 앱에 끼우기.
**플라밍고 후드는 만들지 마세요** — 앱이 3D로 자동으로 씌웁니다. 후드 벗은 모습만 만들면 됩니다.

## 1. 설치
- VRoid Studio (무료, Apple Silicon 네이티브): https://vroid.com/studio 또는 Steam
- 새 캐릭터 → **여성 베이스** 선택

## 2. 레시피 (target-human.png 기준)
| 부위 | 설정 |
|---|---|
| 얼굴 | 성인 비율(아동 X), 차분한 미소, 눈꼬리 약간 올림 |
| 눈동자 | 회청색~네이비 (#4a5578 근처), 하이라이트 크게 |
| 머리 | **다크 네이비** (#232a4d 근처). 앞머리: 오른쪽으로 쓸어넘긴 사이드뱅. 뒷머리: 낮게 묶음/올림머리(후드 쓸 캐릭터라 짧게 정리된 실루엣이 좋음). 옆머리 몇 가닥 |
| 체형 | 성인 여성, 표준 |
| 의상 | 흰색 트랙재킷 계열 프리셋(후디/재킷) 선택 → **텍스처 편집**으로 코랄핑크(#f2799e) 트림·지퍼 라인, 네이비 카라. 이너는 흰 티 |
| 표정 | 기본 제공 blink/aa/happy 등 그대로 (앱이 표준 표정을 사용) |

완벽하지 않아도 됩니다 — 헤어 컬러 + 흰 재킷 + 코랄 포인트만 맞으면 후드 씌우는 순간 "그 캐릭터"로 읽혀요.
텍스처 트림이 어려우면 흰 재킷만으로 1차 진행 → 나중에 같이 다듬어도 됩니다.

## 3. 내보내기 & 교체
1. 우상단 **내보내기 → VRM 내보내기** (VRM 0.x / 1.0 둘 다 지원됨)
2. 머티리얼 수 줄이기 옵션은 기본값 OK
3. 나온 `.vrm` 파일을 → `~/repos/mingo-mate/public/models/placeholder.vrm` 에 덮어쓰기
   (또는 새 이름으로 두고 `src/model/index.ts` 상단의 모델 경로 상수만 수정)
4. `npm start` — 끝. 트래킹·후드·표정 전부 그대로 적용됩니다.
